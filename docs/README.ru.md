# Topgrade для Alfred

[English](../README.md) · **Русский** · [简体中文](README.zh-CN.md)

Команда `topgrade` в Alfred запускает обновления в одной повторно используемой
сессии терминала. Предпочтителен Ghostty; если его нет или версия слишком старая,
используется стандартный Terminal.app macOS.

- Первый запуск создаёт отдельную вкладку Ghostty или окно Terminal.
- Пока обновление идёт, повторы игнорируются: очереди и дополнительных окон нет.
- После завершения следующий вызов запускает обновление в той же сессии.
- Если её закрыть, следующий вызов создаст новую.
- Повторное использование не меняет фокус. При создании новой вкладки Ghostty
  возможно короткое переключение, затем возвращаются прежние вкладка и панель.

## Установка на новом Mac

Нужны Alfred 5 с **Powerpack**, Python 3.9+ и Topgrade. Если Homebrew уже установлен:

```sh
brew install python topgrade
brew install --cask alfred
```

Ghostty необязателен:

```sh
brew install --cask ghostty
```

1. Скачайте [Topgrade.alfredworkflow](https://github.com/Matrix6892/alfred-topgrade/releases/latest/download/Topgrade.alfredworkflow).
2. Откройте файл и импортируйте его в Alfred.
3. Когда хотите обновить программы, вызовите `topgrade` в Alfred. При первом запуске
   разрешите Alfred управлять выбранным терминалом, когда macOS покажет запрос.

При отсутствии Ghostty Terminal.app выбирается автоматически. Подтверждения и
запросы пароля sudo определяются вашими настройками Topgrade.

## Установка и обновление из исходников

```sh
git clone https://github.com/Matrix6892/alfred-topgrade.git
cd alfred-topgrade
python3 install.py --dry-run
python3 install.py
```

Установщик находит активные настройки Alfred, в том числе в папке синхронизации.
Меняет только этот workflow, сохраняя предыдущую папку в `Topgrade Workflow Backups`
рядом с набором настроек. Другие workflows и настройки Topgrade сохраняются.
Перед обновлением workflow закройте выделенную сессию Topgrade: следующий запуск
загрузит новую версию кода.

Для нестандартного расположения:

```sh
python3 install.py --preferences "/path/to/Alfred.alfredpreferences"
```

## Поведение и настройки

Для создания вкладок нужен Ghostty 1.3.1+. Штатный интерфейс Terminal.app создаёт
**окно**, поэтому резервный вариант использует одно отдельное окно. Первое создание
может вывести терминал на передний план; повторы фокус не меняют.
Сессия предназначена для Topgrade: между обновлениями она ждёт следующего вызова,
вместо обычного приглашения оболочки. Предыдущий вывод доступен прокруткой.

Если есть `~/.local/bin/topgrade`, используется этот пользовательский запуск.
Иначе Topgrade ищется в PATH и стандартных папках Homebrew. Настройки исходного
компьютера не копируются, автоматические подтверждения не навязываются.
При необходимости настройте `~/.config/topgrade.toml` обычным способом.

Необязательные переменные окружения в настройках workflow Alfred:

| Переменная | Назначение |
| --- | --- |
| `TOPGRADE_TERMINAL` | `auto` по умолчанию, `terminal` или `ghostty` |
| `TOPGRADE_BINARY` | Полный путь к своему исполняемому файлу или скрипту запуска |
| `TOPGRADE_PYTHON` | Полный путь к Python 3.9+, если он установлен иначе |

Открытая сессия сохраняет выбранный терминал. Перед сменой приложения закройте её.
Восстановленная вкладка Ghostty ждёт команды: восстановление окна само по себе
не начинает обновление.

## Если что-то не работает

- **Отказ в автоматизации:** Системные настройки → Конфиденциальность и безопасность
  → Автоматизация → Alfred; разрешите Ghostty или Terminal. Ошибка разрешения
  не перенаправляет обновление в другое приложение.
- **Сессия не отвечает:** закройте только выделенную вкладку или окно Topgrade и повторите.
- **Нет Python:** установите его через Homebrew или задайте `TOPGRADE_PYTHON`.
- **Ghostty создаёт окно вместо вкладки:** выйдите из нестандартного полноэкранного
  режима, в котором вкладки недоступны.
- **Удаление:** закройте сессию, затем удалите workflow Topgrade в настройках Alfred.
  Службы и объекты автозапуска не устанавливаются.

Диагностические данные находятся в `~/Library/Caches/topgrade-alfred/`.
Они остаются на этой машине и не входят в репозиторий или опубликованный файл.

## Проверки и сборка

Дополнительные пакеты Python не требуются:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/build.py
```

Внутренний режим `workflow/run.sh --check` проверяет версию без обновления программ.
Он предназначен для разработки и не имеет отдельной команды в Alfred.

Результат — `dist/Topgrade.alfredworkflow` с воспроизводимым содержимым архива.
Тесты проверяют повторы, повторное использование, ошибки, закрытие, ожидание после
восстановления, выбор Terminal при отсутствии Ghostty, поиск Topgrade, резервные
копии при установке и воспроизводимость пакета. Проверка GitHub работает на macOS,
компилирует скрипт Terminal и не обновляет программы.

Интерфейс Ghostty сверялся с версией 1.3.1. Проверка версии в настоящем Terminal.app
подтвердила создание и повторное использование той же сессии без изменения числа
окон и выбранного окна. Полное интерактивное обновление и полный
перезапуск приложения — отдельные ручные проверки; тесты их не выполняют.
Подробности: [контракт работы](ARCHITECTURE.md).
